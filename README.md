# Statistical and Economic Evaluation of Volatility Term-Structure Forecasts

Replication code for *Statistical and Economic Evaluation of Volatility Term-Structure
Forecasts: A Paired Placebo Design Applied to VIX Futures* (Schneider,Formentin ,Raffaelli, 2026).

The paper asks whether the S&P 500 implied-volatility term structure can be forecast, and
whether such a forecast can be monetised on VIX futures. The answer to the second question
is no, and the contribution is the apparatus that lets that "no" be a **bound** rather than
a failure to detect: the nested null is pushed through the entire economic pipeline, so that
two portfolios differ in the forecast and in nothing else, and the overlap in their positions
shrinks the standard error of the paired difference.


---

## Quick start

```bash
pip install -r requirements.txt
python paper_numbers.py stat      # any part name, see the table below
python paper_numbers.py mech      # the retraction of the spanning result
```

Every number printed in the paper is regenerated by `paper_numbers.py`, one section at a
time, and merged into `results/numbers.json`. Nothing in the text is typed by hand.

Most parts run in under a minute. The ones that bootstrap are slower: `mech` resamples
2,000 circular shifts at six horizons, and `spa`, `cwboot` and `vxdirect` each run 2,000
block resamples, so allow a few minutes for those.

To check the whole paper at once, run `Notebook_Revision.ipynb`: its final cell compares
every value against a hand-copied dictionary of what the PDF actually says. **80 checks,
0 failures** on the current version.

## Modules

| File | Role |
|---|---|
| `ts_extract.py` | raw SPX option chains to a daily term structure: forward recovered from put-call parity, Black-Scholes inverted numerically on mid-quotes, Nelson-Siegel three-factor fit |
| `vix_lab.py` | forecasting toolkit, walk-forward protocol with embargo, skill against the random walk, backtest |
| `futures_signed.py` | the economic test: constant-maturity VIX futures position, walk-forward projection of the forecast into futures units, the ternary rule, the nested placebo, Lo (2002) standard errors |
| `ts_models.py` | Box-Jenkins AR/MA/ARMA/ARIMA, stationarity and residual diagnostics, BIC order selection |
| `slope_spread.py` | the 60-day against 30-day calendar spread (reported, not relied upon) |
| `paper_numbers.py` | the single source of truth: every figure in the paper |
| `review_tests.py` | independent recomputation used during review |

## The guard

Any forecasting study can be destroyed by a one-day misalignment between a forecast and its
target, and the error is invisible in the output. `Notebook_Revision.ipynb` opens with an
automated guard: every forecaster is run on a **pure simulated random walk**, where skill
must be indistinguishable from zero. A one-step misalignment on a random walk shows up as a
skill of `1 - sqrt(1 + 1/h)`, that is -41% at h=1 and -9.5% at h=5. All forecasters pass.

Run this before trusting anything else.

## Data

| Source | In this repo | Licence |
|---|---|---|
| CBOE VIX futures settlements (VX), 171 contracts, 2013-2026 | yes, `data/vix_futures_cfe/` | public CBOE data |
| SPX end-of-day option chains, 2010-2023, ~1.7 GB | **no** | optionsDX, see below |
| Fitted daily term structure (derived) | yes, `ts_reinvert.parquet` | derived output, not raw quotes |
| Forecast caches | yes, `cache/*.pkl` | derived output |

The raw option chains are redistributed by [optionsDX](https://www.optionsdx.com) and are not
included here. `ts_reinvert.parquet` is the **derived** daily curve, three Nelson-Siegel
factors and a handful of constant-maturity points per day, which is what every part of
`paper_numbers.py` actually consumes. With it the whole paper replays without the 1.7 GB of
raw quotes.

To rebuild the curve from raw chains instead, download the archive from optionsDX into
`data/bid_ask_quotes/` and use `ts_extract.py`.

`ts_optionsdx.parquet` is the alternative construction of Appendix B, which reads the
vendor's own implied volatilities rather than inverting mid-quotes.

## Reproducing the headline numbers

```bash
python paper_numbers.py cwboot    # h=30 Clark-West: p moves from 0.024-0.032 to 0.051-0.069
python paper_numbers.py rw        # Romano-Wolf: 17 survivors of 42, none of them monthly
python paper_numbers.py mech      # unrestricted t on the forecast = 0.10; permutation p = 0.041
python paper_numbers.py spa       # Hansen SPA over 45 configurations: p = 0.82
python paper_numbers.py vxdirect  # futures curve modelled directly, 2013-2026
```
